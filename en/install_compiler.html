Frequently Asked Questions

What dependencies will the setup I create need on the client's machine?

None! The generated installer is a standalone binary. It doesn't require prior installation of Python, Java, or C++ Redistributable on your client's computer (unless you add those files to the installation package yourself).

How does the built-in Icon Converter work?

It acts in two ways: (1) Reverse engineering by extracting native icons from DLLs and EXEs on your computer. (2) Converting your PNG arts into multi-resolution .ICO files, preserving Alpha channels (32-bit) which are crucial for perfect Windows shortcuts.

Does it work for software compiled with PyInstaller or cx_Freeze?

Yes! In fact, it is highly recommended for Python applications. Since PyInstaller usually generates folders with dozens of libraries (DLLs and PYDs), Install Compiler merges all these loose files into a single, elegant, and compressed `Setup.exe` file.
