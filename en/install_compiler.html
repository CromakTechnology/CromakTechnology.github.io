The 4 Pillars of Our Architecture

  • Advanced Injection & Registry

    Create Windows Registry keys (Regedit), dynamically modify INI files, bind custom file extensions to your application, and apply binary text patches directly using hexadecimal offsets.

  • Extreme Compression (LZMA + UPX)

    Don't waste your user's bandwidth. The engine offers compression profiles ranging from Fast to 'Extreme', fusing LZMA and UPX algorithms to drastically reduce final installer size by up to 70%.

  • Hybrid Smart Uninstaller

    The build engine automatically generates an uninstaller for your software. Choose between the ultra-lightweight "Slim" native engine (Tkinter) in the kilobyte range, or the robust PyQt6 visual wizard. Clean orphaned registry keys, auto-terminate running processes, and wipe AppData.

  • Integrated Icon Studio (PNG to ICO)

    Stop relying on sketchy third-party web converters. Use the built-in studio to reverse-engineer and extract icons from foreign DLLs/EXEs, or convert your PNG/JPG artworks into native 32-bit (Alpha) Windows .ico files.

Frequently Asked Questions (FAQ)

Can I commercially sell the software packaged with Install Compiler? Do I owe royalties?

No! You pay zero royalties. All installers and packages you compile with Cromak Install Compiler remain 100% your own intellectual property. You can distribute and sell them to unlimited end users without any fees or recurring cuts.

Do I need programming skills to build installers?

No! Unlike legacy tools such as Inno Setup and NSIS, which require mastering complex scripting languages like Pascal or custom syntax, Cromak Install Compiler is 100% visual. You configure extraction paths, registries, EULAs, icons, and flags through organized tabs with real-time preview (WYSIWYG).

Does it support applications built with PyInstaller, cx_Freeze, or Nuitka?

Seamlessly! It is heavily optimized for Python developers. When PyInstaller generates folders with dozens of loose libraries (.dll, .pyd), Install Compiler bundles everything into a single, elegant `Setup.exe` with LZMA + UPX compression, reducing download sizes by up to 70%.

Does the final generated installer require client-side runtimes?

None! The generated installer is a standalone, native Windows PE binary. It runs independently without requiring prior installation of Python, Java, .NET, or C++ Redistributable packages on your client's machine (unless your own software specifically requires them).
