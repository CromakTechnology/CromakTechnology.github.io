The 3 Pillars of the New Tab

Customize, save, and access your essential services without relying on third-party servers.

🎨 100% Customizable Metro UI

Clean block-based interface with full support for color, text, and opacity customization. Change the look in real-time to match your style.

💾 LocalStorage (Offline)

Privacy is guaranteed. All modifications, links, and preferences you change are stored directly in your local browser memory.

🔄 Portable Backups

Access the preferences panel to export your entire page as a base64 file. Import it on any other machine and recover your layout in seconds.

Layout Overview

Click the images to expand and view interface details.

Home Screen and Categories

The main page comes pre-linked to dynamic subcategories like videos, music, AI, games, and stores. A giant highlight in the center exclusively for Google Services.

Block Configuration

Press ALT + Click on any block to open the editing modal. Change the title, set a new destination link, change the icon image, and adjust the panel's background color.

General Preferences

Absolute control over the overall design. Choose a new background wallpaper, adjust the color and transparency of all panels, and manage your Backup files.

Direct Name Editing

Just need to rename? The system allows for quick dynamic editing of service names directly on the panel, ensuring fluidity in your daily workflow.

Search Engines

Far beyond Google. Dynamically select which engine you want to search (Bing, DuckDuckGo, Amazon, and others) directly from the same central bar.

About the Software

Informational window detailing the current version (v1.1) of the Metro UI Interface, designed to be a smart and fully modular shortcut panel.

Advanced Web Engineering

  • Dynamic DOM Modifications

    JavaScript handles each visual change instantly without reloading the page, maintaining the feel of a fast native application.

  • Clean Rendering

    The HTML5 and CSS3 source code is minified and organized, avoiding heavy frameworks and ensuring immediate loading.

  • Placeholder System

    Ready for safe use. The repository version features neutral blocks and "Add New" images to prevent online content violations.

⚡ Hybrid Hosting

You can use the ready-made version running on GitHub Pages (where your data is saved locally on your machine) or download the files and use them as an offline extension in your browser.
