Knowledge Base

Payments and Licenses

How do I receive my license after purchase?

Processing is instantaneous. As soon as payment is confirmed, your unique activation key and installation instructions are sent directly to your registered email.

Can I use the license on more than one computer?

It depends on your plan. The Lifetime Personal license allows activation on up to 3 simultaneous computers. The Monthly and Annual licenses are limited to 1 active device at a time.

Do the softwares need internet to work?

Only the initial license activation requires an internet connection. The vast majority of our tools are designed to operate 100% offline, guaranteeing the absolute privacy of your local data.

DeepClean Suite

Does DeepClean offer protection before deep cleaning?

Yes. As a security measure, the system strongly recommends creating a Registry Clone (.dcr). If an extreme modification breaks the Windows boot, you can use the Restore Screen to restore this clone and revive the PC instantly.

What does Cromak Sentinel do on my computer?

The native component "cbsservice.exe" acts as a guardian service in the background that orchestrates Cromak Sentinel, functioning as a real-time protection EDR.

How does the uninstaller ensure no files are left behind?

Our tool goes beyond common uninstallers. The software uses the "Sniper" engine, designed to obliterate hidden program traces by scanning directly from the executable path after the standard uninstallation.

Password Guard

Does Password Guard store my passwords in the cloud?

No. The system is based on Zero-Knowledge architecture. This means we do not have cloud servers and we do not have access to your Master Key or database.

What happens if I lose my chave.key?

Your vault system consists of the database (`dados.db`) and your Cryptographic Key (`chave.key`). If you format the computer and lose the "chave.key" file, not even the software creator will be able to recover your passwords. You must always create a "Shielded Backup" on a USB Flash Drive.

Is there a defense against Brute Force password theft?

Yes. Entering the wrong password on the login screen 5 times activates the software's security protocol, which permanently destroys the local "chave.key" to prevent third parties from hacking your database via brute force.

What is the Shredder Protocol?

It is a military-grade forensic tool available in the PRO version. When activating the Shredder Protocol, the program will overwrite the original file (like PDFs or sensitive photos) with absolute zeros before deleting it from Windows, making it immune to forensic recovery software.

Install Compiler

Does the compiler reduce the final size of my executable file?

Absolutely. The system uses heavy compression algorithms, allowing the use of LZMA compression and the UPX executable engine (when enabled) to minimize the disk footprint of your final package.

Does it automatically generate an uninstaller?

Yes. During the build phase, the engine automatically generates and compiles a "slim uninstaller" with a graphical user interface (GUI), which will be invisibly included in your installer.

Can I digitally sign my installers?

Yes. Install Compiler integrates perfectly with Microsoft's official SignTool, allowing you to inject and apply your Digital Certificate (.pfx) with a Timestamp to avoid antivirus warnings.

Metadata Remover

Can I clean multiple files at once?

Yes. The software operates through batch processing, allowing you to import dozens of loose files or entire folders for simultaneous sanitization.

What happens to the original files after cleaning?

You choose. The system allows exporting the clean versions to a specific folder, compressing them into a .ZIP file, or activating the "Overwrite" mode, which irreversibly destroys the original file and replaces it with the clean version.

Does the program delete the edit history of PDFs or Word documents?

Yes. The PRO module features structural document sanitization, which actively removes revision history, authors, and hidden comments. In PDF files, the system can even apply invisible ink to trackers.

PNG To ICO Converter

Is it possible to extract icons from installed programs?

Yes. The system has a reverse engineering forensic engine capable of analyzing Windows binary files (EXE/DLL) and extracting original icon matrices from inside them.

What color matrices and resolutions does the software support?

The tool supports full compilation for various architectures. It generates resolutions from 512px down to 16px. Regarding color depth, it supports 32-bit matrices (True Color + Alpha), 8-bit (256 legacy colors), and even 4-bit (16 colors for very old systems).

Web To Apk Compiler

Does the compiler work for local (offline) sites?

Yes. The system supports two modes: Online Mode (converts an active URL into an App) and Offline Mode, which allows packaging an entire folder containing HTML/CSS/JS files locally in the APK, allowing it to work without internet.

What happens if I lose my Keystore or password?

Maximum attention: if you lose the Keystore or its respective passwords, you will NEVER AGAIN be able to send updates of your app to Google Play. The old application in the store will become inaccessible for edits, forcing you to create a new one and lose your downloads.

What exclusive features are in the PRO engine?

Version 2.0 offers integrated monetization (native injection of AdMob blocks without programming), a Dynamic Side Menu (Navigation Drawer) injected directly into the Android interface, and a "Highly Cached" mode for ultra-fast loading.
