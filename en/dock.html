Key Features & Architecture Highlights

  • Smooth Zoom Physics & 3 Visual Modes

    Continuous magnification curve without visual stutter. Choose between Bubble (classic Gaussian), Plateau (broad peak for adjacent items), and Simple Zoom, featuring fully configurable zoom radius and transition duration.

  • Up to 4 Independent Simultaneous Docks

    Position docks on any screen edge concurrently: bottom edge for primary apps, top edge for productivity tools, left for drives and folders, and right for hardware monitoring. Each dock maintains isolated icon lists and auto-hide rules.

  • Real-Time Hardware & System Widgets

    Live monitoring for CPU, RAM, GPU, and Network traffic with instant visual rings. Includes a smooth analog clock and a dual-state Recycle Bin widget supporting instant emptying via context menu.

  • Running Process Indicators & Launch FX

    Instantly spot active programs with orientation-aware indicator arrows. Launch applications with tactile visual feedback: Bounce, Spin, or Pulse animations.

  • RocketDock Importer & Native Drag-and-Drop

    Migrate in seconds! The built-in importer parses RocketDock Settings.ini files and reconstructs your layout instantly. Drag and drop any executable, folder, or drive directly onto the bar.

  • 40+ Built-in Themes & Deep Customization

    Full compatibility with classic .ini and modern .json skins, retro font styling, drop shadows with blur, border opacity adjustments, and edge-hover auto-hiding.

Frequently Asked Questions (FAQ)

Is Cromak Dock truly free?

Yes! Cromak Dock is provided for free by Cromak Technology, with all features completely unlocked, no shortcut limits, and zero ads. The donation button is purely voluntary for users who wish to support independent software maintenance.

Can I use my classic RocketDock themes?

Yes! Cromak Dock's rendering engine was architected with native backward compatibility to load and render classic .ini skin files as well as modern .json themes. Simply drop the theme folder into the themes directory.

How does the 4-dock multi-screen support work?

You can enable up to 4 docks simultaneously via the right-click context menu or preferences window. Each dock can be pinned to any screen edge (Bottom, Top, Left, Right), with its own independent app shortcuts and auto-hide behaviors.

Where are settings and cached icons stored?

Following strict Windows guidelines, all configuration files (settings.json) and extracted icon caches are stored in your user profile folder (%APPDATA%\Cromak Technology\Dock). The Program Files installation directory is never modified at runtime.
