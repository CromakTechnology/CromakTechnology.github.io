Deep Protection, Simple Management

Forget exhausting navigation through the Group Policy Editor (gpedit.msc) or dangerous Registry modifications. Cromak SysLock brings the power of corporate administration to a clean, safe, and user-friendly interface, allowing you to restrict or allow critical access in seconds.

🔒 Critical System Locks

Instantly disable tools that could compromise machine integrity. With a single click, prevent the opening of the Task Manager (Ctrl+Alt+Del), Registry Editor (regedit), and Command Prompt (CMD).

🛑 Modification Prevention

Prevent unwanted installations by blocking the Windows Installer (MSI). Restrict access to Windows Update and classic or modern configuration panels, ensuring the system stays exactly as you configured it.

🖥️ Restrictive Customization

Block desktop wallpaper changes, hide the C: drive to prevent vital file exploration, and disable the desktop context menu. Perfect for kiosks, public computers, or monitored corporate environments.

Everything You Need on a Single Screen

SysLock's unified dashboard was designed with elegance and usability in mind. It separates each access level into intuitive categories so you have absolute control over the operating system without wasting time looking for hidden options.

Security Tab: End-to-End Control

The first tab centralizes the essential policies for system survival. Here you can remove maintenance tools from the hands of the common user with a single click. Block the Task Manager to prevent forced termination of your processes, hide the Registry Editor against improper manipulation, and prevent silent installations by blocking the Program Installation window (MSI).

System & Panel Tab: Administrative Shielding

Designed to shield the computer, this section manages global configuration access. Limit Windows Update to prevent unexpected updates from breaking corporate software, and prohibit the opening of the Control Panel and PC Settings. Furthermore, it features an exclusive button for handling Local Policies (GPO), offering absurd ease in resetting and deploying rules in your environment.

Instant Action

No more rebooting the computer just to see the effects of a group policy. SysLock applies most of its locks immediately through a transparent Explorer restart and native Registry recording.

GPO Maintenance

In addition to configuring standalone restrictions, the utility features a powerful built-in GPO cache cleanup and forced application (gpupdate) tool, allowing you to safely reset policies.

Dynamic Multi-language

An interface that caters to professionals everywhere, fully dynamically translated into Portuguese, English, and Spanish. The program remembers your choices in a secure offline file.

Secure, Portable, and Reliable Engineering

  • Single Executable (Portable)

    Distributed in a practical standalone ".EXE" format. SysLock does not require complex installers or dependencies running in the background, making it the ideal companion on any IT technician's flash drive.

  • Native Policy Handling

    Instead of relying on amateur scripts, the program uses native Windows Registry APIs (winreg) for secure memory writing (HKLM and HKCU), minimizing corruption rates or permission failures.

  • Absolute Privacy (Zero Telemetry)

    Cromak Technology takes your data seriously. SysLock runs 100% offline, does not connect to external servers, does not send reports, and stores your settings solely on the client's machine.

⚠️ Usage and Administrative Level

Cromak SysLock applies deep system restrictions and requires execution with Administrator privileges. Exercise caution when blocking the Registry Editor and Command Prompt simultaneously, so as not to lock yourself out of the operating system's advanced recovery options.
