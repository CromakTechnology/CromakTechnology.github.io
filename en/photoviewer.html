Native JPEG XL (.JXL) Support — No Microsoft Store Extensions Needed

JPEG XL (.jxl) is the official next-generation successor to JPEG: delivering up to 60% smaller file sizes with superior visual fidelity, Alpha transparency, HDR support, and animation. While the legacy Windows 7 viewer rejects the format entirely and Windows 11 requires extra Microsoft Store codec extensions, Cromak Photo Viewer v1.4.6 embeds a multi-threaded .jxl decoder directly inside the standalone engine:

Zero External Codecs: Opens .jxl files straight out of the box
Static & Animated JXL: Frame-accurate playback
Full Editing Support: Rotate, resize, and save .jxl natively
1-Click Association: Set as Windows default for .jxl

High-Performance Engineering in PyQt6

  • Native Decoding + JPEG XL & Animated Formats

    Effortlessly loads JPG, PNG, BMP, WEBP, JPEG XL (.jxl), animated GIFs, and multi-page files (.ico / .tiff) with automatic EXIF orientation and smart on-demand pan cursor.

  • Built-in Productivity (Batch, Resize & USB)

    Features a 2-phase collision-safe batch renaming engine, a high-precision resizer using SmoothTransformation filtering, and real-time Win32 removable USB drive detection.

  • Non-Blocking Multithreaded Architecture

    Directory scanning across thousands of photos, sidebar thumbnail generation, and adjacent image preloading run in dedicated background threads so the UI never freezes.
