Frequently Asked Questions

Do I need to know how to code in Java or Kotlin?

Absolutely not. The visual dashboard does all the heavy lifting of XML and Smali editing for you. Just fill in the fields and click compile.

Is the application accepted on the Google Play Store?

Yes! The system performs memory alignment (Zipalign) and signs the APK with the strict V1 and V2 signatures required by Google, generating an app ready for production.

What if Android updates its API requirements?

Google requires Target API updates annually. Users with Annual or Lifetime licenses receive engine updates (new `base.apk`) for free to keep their apps always compliant.
