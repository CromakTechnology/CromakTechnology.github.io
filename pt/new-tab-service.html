Os 3 Pilares da Nova Aba

Personalize, salve e acesse seus serviços essenciais sem depender de servidores de terceiros.

🎨 Metro UI 100% Customizável

Interface baseada em blocos limpos, com suporte total para customização de cores, textos e opacidade. Altere o visual em tempo real para combinar com o seu estilo.

💾 LocalStorage (Offline)

A privacidade é garantida. Todas as modificações, links e preferências que você altera ficam armazenadas diretamente na memória do seu navegador local.

🔄 Backups Portáteis

Acesse o painel de preferências para exportar a sua página inteira em um arquivo base64. Importe em qualquer outra máquina e recupere seu layout em segundos.

Visão Geral do Layout

Clique nas imagens para expandir e ver os detalhes da interface.

Tela Inicial e Categorias

A página principal já vem linkada para subcategorias dinâmicas como vídeos, músicas, IA, games e lojas. Destaque gigante no centro exclusivo para os Serviços do Google.

Configuração do Bloco

Pressione ALT + Clique em qualquer bloco para abrir o modal de edição. Altere o título, defina um novo link de destino, mude a imagem do ícone e ajuste a cor de fundo do painel.

Preferências Gerais

Controle absoluto sobre o design geral. Escolha uma nova imagem para o papel de parede, regule a cor e a transparência de todos os painéis e gerencie seus arquivos de Backup.

Edição Direta do Nome

Precisa apenas renomear? O sistema permite edição dinâmica rápida dos nomes dos serviços diretamente no painel, garantindo fluidez no seu fluxo de trabalho diário.

Motores de Busca

Muito além do Google. Selecione dinamicamente em qual mecanismo você quer pesquisar (Bing, DuckDuckGo, Amazon e outros) a partir da mesma barra central.

Sobre o Software

Janela informativa que detalha a versão atual (v1.1) da Interface Metro UI, desenvolvida para ser um painel de atalhos inteligente e totalmente modular.

Engenharia Web Avançada

  • Modificações Dinâmicas no DOM

    O JavaScript lida com cada alteração visual instantaneamente sem recarregar a página, mantendo a sensação de uma aplicação nativa rápida.

  • Renderização Limpa

    O código-fonte em HTML5 e CSS3 é minificado e organizado, evitando frameworks pesados e garantindo carregamento imediato.

  • Sistema de Placeholder

    Pronto para o uso seguro. A versão de repositório conta com blocos neutros e imagens de "Adicionar Novo" para evitar violações de conteúdo online.

⚡ Hospedagem Híbrida

Você pode usar a versão pronta rodando no GitHub Pages (onde seus dados ficam salvos localmente na sua máquina) ou baixar os arquivos e usar como extensão offline no seu navegador.

Compatibilidade Universal de Navegadores

Desenvolvido com padrões modernos da web para garantir que a sua experiência Metro UI funcione de forma impecável, independente da sua escolha de navegador.
