Pagamentos e Licenças

Como recebo a minha licença após a compra?

O processamento é instantâneo. Assim que o pagamento é confirmado, a sua chave de ativação única e as instruções de instalação são enviadas diretamente para o seu e-mail cadastrado.

Posso utilizar a licença em mais de um computador?

Depende do seu plano. A licença Pessoal Vitalícia permite a ativação em até 3 computadores simultâneos. Já as licenças Mensais e Anuais são limitadas a 1 dispositivo ativo por vez.

Os softwares precisam de internet para funcionar?

Apenas a ativação inicial da licença requer conexão com a internet. A vasta maioria das nossas ferramentas foi desenhada para operar de forma 100% offline, garantindo a privacidade absoluta dos seus dados locais.

DeepClean Suite

O DeepClean oferece proteção antes de limpezas profundas?

Sim. Como medida de segurança, o sistema recomenda fortemente criar um Clone do Registro (.dcr). Se uma modificação extrema quebrar a inicialização do Windows, você poderá utilizar a Tela de Restauração para restaurar este clone e reviver o PC na hora.

O que o Cromak Sentinel faz no meu computador?

O componente nativo "cbsservice.exe" atua como um serviço guardião em segundo plano que orquestra o Cromak Sentinel, funcionando como um EDR de proteção em tempo real.

Como o desinstalador garante que nenhum arquivo fique para trás?

A nossa ferramenta vai além dos desinstaladores comuns. O software utiliza o motor "Sniper", projetado para obliterar rastros de programas ocultos varrendo diretamente a partir do caminho do executável após a desinstalação padrão.

Password Guard

O Password Guard armazena minhas senhas na nuvem?

Não. O sistema é baseado na arquitetura Zero-Knowledge (Conhecimento Zero). Isso significa que nós não temos servidores em nuvem e não possuímos acesso à sua Chave Mestra ou banco de dados.

O que acontece se eu perder a minha chave.key?

O seu sistema de cofre é composto pelo banco (`dados.db`) e pela sua Chave Criptográfica (`chave.key`). Se você formatar o computador e perder o arquivo "chave.key", nem mesmo o criador do software poderá recuperar as suas senhas. Você deve sempre criar um "Backup Blindado" em um Pen Drive.

Existe defesa contra roubo de senhas por Força Bruta?

Sim. Errar a senha na tela de login 5 vezes ativa o protocolo de segurança do software, que destrói a "chave.key" local permanentemente para impedir que terceiros invadam o seu banco de dados via força bruta.

O que é o Protocolo Shredder?

É uma ferramenta forense de nível militar disponível na versão PRO. Ao ativar o Protocolo Shredder, o programa irá sobrescrever o arquivo original (como PDFs ou fotos sensíveis) com zeros absolutos antes de apagá-lo do Windows, tornando-o imune a softwares forenses de recuperação.

Install Compiler

O compilador reduz o tamanho final do meu arquivo executável?

Com certeza. O sistema utiliza algoritmos de compressão pesados, permitindo o uso da compressão LZMA e do motor executável UPX (quando ativado) para minimizar a pegada em disco do seu pacote final.

Ele gera um desinstalador automaticamente?

Sim. Durante a fase de build, o motor gera e compila automaticamente um "slim uninstaller" com interface gráfica (GUI), que será incluído de forma invisível no seu instalador.

Posso assinar digitalmente meus instaladores?

Sim. O Install Compiler integra-se perfeitamente com a ferramenta oficial SignTool da Microsoft, permitindo injetar e aplicar o seu Certificado Digital (.pfx) com carimbo de data/hora (Timestamp) para evitar alertas de antivírus.

Metadata Remover

Posso limpar vários arquivos de uma só vez?

Sim. O software opera através de processamento em lote (Batch), permitindo importar dezenas de arquivos soltos ou pastas inteiras para sanitização simultânea.

O que acontece com os arquivos originais após a limpeza?

Você escolhe. O sistema permite exportar as versões limpas para uma pasta específica, compactá-las em um arquivo .ZIP, ou ativar o modo "Sobrescrever", que destrói o arquivo original de forma irreversível e o substitui pela versão limpa.

O programa apaga o histórico de edições de PDFs ou Word?

Sim. O módulo PRO conta com higienização estrutural de documentos, que remove ativamente histórico de revisões, autores e comentários ocultos. Em arquivos PDF, o sistema pode até aplicar tinta invisível em rastreadores.

PNG To ICO Converter

É possível extrair ícones de programas instalados?

Sim. O sistema possui um motor forense de engenharia reversa capaz de analisar arquivos binários do Windows (EXE/DLL) e extrair matrizes de ícones originais de dentro deles.

Quais matrizes de cor e resoluções o software suporta?

A ferramenta suporta a compilação completa para diversas arquiteturas. Ela gera resoluções desde 512px até 16px. Quanto à profundidade de cor, há suporte a matrizes de 32 bits (True Color + Alpha), 8 bits (256 cores legado) e até 4 bits (16 cores para sistemas muito antigos).

Web To Apk Compiler

O compilador funciona para sites locais (offline)?

Sim. O sistema suporta dois modos: o Modo Online (converte uma URL ativa em App) e o Modo Offline, que permite empacotar uma pasta inteira contendo arquivos HTML/CSS/JS localmente no APK, permitindo seu funcionamento sem internet.

O que acontece se eu perder a minha Keystore ou a senha?

Atenção máxima: se você perder a Keystore ou as suas respectivas senhas, você NUNCA MAIS poderá enviar atualizações do seu app para a Google Play. O aplicativo antigo na loja ficará inacessível para edições, forçando você a criar um novo e perder seus downloads.

Quais recursos exclusivos existem no motor PRO?

A versão 2.0 oferece monetização integrada (injeção nativa de blocos AdMob sem programar), Menu Lateral Dinâmico (Navigation Drawer) injetado diretamente na interface Android e um modo "Highly Cached" para carregamento ultrarrápido.
