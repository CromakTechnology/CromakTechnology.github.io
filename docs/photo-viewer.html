Cromak PhotoViewer — Manual do Usuário

Guia operacional para visualização rápida de imagens, carregamento instantâneo sem telemetria e associação de arquivos em sistemas Windows.

Versão 1.4.2 Portátil / Standalone Zero Telemetria

01 Visão Geral da Ferramenta

O Cromak PhotoViewer resgata a agilidade dos visualizadores clássicos com uma engine moderna de aceleração por renderização nativa. Abre instantaneamente imagens de altíssima resolução sem consumir gigabytes de memória RAM.

02 Execução Portátil (Standalone)

Sem Poluição no Registro

O PhotoViewer não exige instalador com serviços de fundo:

  1. Basta extrair o arquivo e executar o PhotoViewer.exe.
  2. As configurações de tema e idioma são armazenadas de forma segura na pasta AppData do usuário.

03 Associação de Arquivos (Tornar Padrão)

Para configurar o PhotoViewer como o aplicativo padrão para abrir fotos no Windows:

Método Integrado (Em 1 Clique)

Abra o aplicativo, vá na aba Preferências e selecione Associação de Extensões para registrar os formatos desejados no shell do Windows.

04 Formatos Suportados

Categoria Extensões Suportadas
Imagens Web PNG, JPG / JPEG, WEBP, GIF, BMP
Ícones e Vetoriais ICO, TIFF / TIF, SVG

05 Compromisso Zero Telemetria

Diferente dos visualizadores de fotos modernos que rastreiam metadados das imagens e enviam relatórios para servidores na nuvem, o Cromak PhotoViewer é 100% offline. Nenhuma miniatura, caminho de arquivo ou metadado EXIF é transmitido.
