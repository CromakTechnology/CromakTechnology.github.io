Cromak Network Fix — Manual do Usuário

Guia operacional para diagnóstico avançado de conectividade, reset de pilha TCP/IP, renovação de concessão DHCP e restauração da API Winsock em sistemas Windows.

Versão 1.0.0 Código 100% Nativo Requer Elevação Admin

01 Visão Geral da Ferramenta

O Cromak Network Fix é um utilitário nativo de alto desempenho desenvolvido para restaurar a integridade das conexões de rede em computadores com Windows 10 e Windows 11. Elimina rotinas repetitivas de terminal (cmd/PowerShell), unificando diagnósticos e reparos em uma interface gráfica moderna e responsiva.

Objetivos Técnicos

  • Resolver instantaneamente problemas de navegação com "Sem Internet / Conectado Seguro".
  • Eliminar conflitos de roteamento, tabelas ARP corrompidas e caches DNS defasados.
  • Restaurar camadas de baixo nível do subsistema Winsock e pilha IP sem a necessidade de formatação.

02 Módulo de Diagnóstico & Telemetria Local

Ferramentas ativas para identificar onde a conexão falhou antes de aplicar qualquer reparo:

Ferramenta Comando Subjacente Finalidade Técnica
Ping Test ping -n 4 8.8.8.8 Mede latência e percentual de perda de pacotes contra nós globais confiáveis.
Traceroute tracert -d [destino] Mapeia todos os saltos de roteadores até o host final, identificando gargalos de rota.
Nslookup nslookup [domínio] Testa se os servidores DNS configurados na placa estão respondendo com registros válidos.
Netstat netstat -ano Examina conexões TCP ativas, portas em escuta (LISTENING) e PIDs associados.
Ipconfig ipconfig /all Extrai parâmetros completos de interfaces (IPv4, IPv6, Gateway, Máscara e Lease Time).

03 Correção, Limpeza e Redefinição

Módulos de reparo cirúrgico integrados com privilégio administrativo:

1. Flush DNS (Esvaziamento de Cache)

Elimina o repositório temporário de resoluções de nome do Windows Resolver. Essencial para quando domínios mudaram de IP ou foram envenenados.

2. Release / Renew DHCP

Força o descarte do IP concedido anteriormente e solicita ao roteador/servidor DHCP local uma concessão renovada com gateway atualizado.

3. Limpeza de Tabela ARP

Apaga o mapeamento entre endereços IP e MAC addresses locais, corrigindo conflitos de IP em switches ou redes corporativas.

4. Reset Winsock (Catálogo de Sockets)

Restaura o subsistema Windows Sockets ao padrão de fábrica, removendo filtros corrompidos de antivírus legados ou malwares. (Requer reinício do computador).

5. Reset TCP/IP Stack

Reescreve as chaves do registro do Windows responsáveis pela camada TCP/IP, recriando as pilhas IPv4 e IPv6 do zero. (Requer reinício do computador).

04 Fluxo Operacional Recomendado

Recomendação de Suporte: Sempre execute o aplicativo como Administrador para garantir que as redefinições no registro do Windows e no catálogo Winsock sejam aplicadas sem restrições de permissão.
  1. Execute o Ping Test. Se houver resposta sem perda de pacotes, a camada física e o gateway estão saudáveis.
  2. Execute o Nslookup. Se falhar, aplique Flush DNS e alterne os servidores para DNS públicos (1.1.1.1 ou 8.8.8.8).
  3. Se persistir o status "Sem Internet", aplique em sequência: Flush DNS → Release / Renew IP → Limpar ARP.
  4. Em cenários críticos de falha de driver ou após remoção de malwares de rede, acione Reset Winsock e Reset TCP/IP e reinicie a máquina.

05 Compromisso Zero Telemetria

O Cromak Network Fix opera 100% em modo local (Zero-Cloud). Nenhum relatório de rede, endereço IP, nome de máquina ou histórico de tráfego é transmitido para a internet. Suas análises pertencem estritamente à sua máquina.
