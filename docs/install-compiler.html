1 Introdução e Filosofia

O Cromak Install Compiler é um sistema avançado de geração de instaladores nativos para o ecossistema Windows. Construído sob uma arquitetura robusta em Python, nosso compilador entrega setups independentes (.exe) com alta taxa de compressão (LZMA/UPX) e interfaces gráficas modernas.

  • Independência: Os instaladores gerados são pacotes standalone. Eles não exigem que o cliente final baixe dependências externas na hora da instalação.
  • UX Internacional: Sistema de detecção de QLocale integrado. O instalador detecta automaticamente o idioma nativo do sistema operacional do cliente.

2 Compatibilidade e Performance

Foco no Futuro, não no Passado.
A arquitetura do Cromak Install Compiler foi concebida visando o máximo desempenho, segurança de memória e velocidade de extração de disco. Por esse motivo, tanto o Builder (Compilador) quanto os executáveis (Setups) gerados por ele são estritamente otimizados e compatíveis apenas com Windows 10 e Windows 11 (Arquitetura 64-bits).

Sistemas legados como Windows 7, Windows 8 ou arquiteturas de 32-bits não são oficialmente suportados. A remoção do suporte a tecnologias defasadas permite que nossos motores de compressão entreguem o ápice da performance sem gargalos de compatibilidade.

3 O Motor do Desinstalador (Atenção ao PyQt6)

Durante a configuração do seu projeto na aba "Desinstalador", você notará duas abordagens para a geração do executável de remoção do seu software (o unins000.exe). É crucial entender a diferença de arquitetura entre elas para evitar reclamações dos seus clientes finais:

✅ Motor Nativo Slim (Tkinter) - RECOMENDADO

O desinstalador nativo padrão (Slim) utiliza uma interface extremamente leve (Tkinter) para manter o arquivo final na faixa dos KBs.

❌ Motor Visual Completo (PyQt6) - NÃO RECOMENDADO

Ativa uma interface rica idêntica à do instalador, mas com um custo de armazenamento altíssimo, não sendo a abordagem recomendada.

ALERTA DE DESEMPENHO E TAMANHO (INFLAÇÃO DO PACOTE)
Não recomendamos o uso do assistente de desinstalação em PyQt6. Ao ativar o assistente visual em PyQt6, o motor precisará embutir novamente todas as bibliotecas robustas (DLLs do Qt, motores de fontes, a própria linguagem Python, etc.) dentro do desinstalador para que ele consiga desenhar a janela na tela.

Isso fará com que a sua pasta de instalação fique significativamente maior (muitas vezes aumentando mais de 30MB apenas para a função de remover os arquivos). Para evitar que seu cliente reclame do tamanho desnecessário do software instalado, opte sempre pelo motor Slim padrão!

4 Recursos Avançados do Setup

O ecossistema do instalador oferece injeções a nível de sistema operacional de forma silenciosa e transparente:

⚙️ Injeção de Registro e Variáveis

Você pode mapear chaves HKEY_LOCAL_MACHINE ou HKEY_CURRENT_USER diretamente pela interface. O instalador também processa macros dinâmicas como #AppData#, #LocalAppData# e #InstallDir# para adaptar caminhos relativos na máquina de cada cliente.

🧹 Limpeza Profunda (Shredder)

Na aba do Desinstalador, você pode mapear rotinas de Auto-Kill (que forçam o encerramento do seu software se o cliente tentar desinstalá-lo com ele aberto) e rotinas de exclusão de rastros, removendo caches e logs soltos na pasta AppData que normalmente ficariam para trás como lixo digital no Windows.

5 Licenciamento PRO & HWID PRO TRIAL 15 DIAS

O Cromak Install Compiler é protegido por um sistema avançado de ativação baseado em Hardware ID (HWID). A versão de avaliação (Trial) permite testar a compilação por tempo limitado. O registro de uma Licença PRO vitalícia remove os limites de dias e garante acesso contínuo aos motores de compilação.

A licença é atrelada diretamente à placa-mãe/processador da máquina do desenvolvedor. Em caso de troca de computador, utilize o botão "Remover Licença" na tela "Sobre" para desvincular seu registro do Registro do Windows atual e permitir a migração segura para o novo hardware.
