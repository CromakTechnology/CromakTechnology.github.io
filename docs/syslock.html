Cromak SysLock — Manual do Usuário

Guia operacional para aplicação cirúrgica de restrições de sistema, bloqueio de ferramentas administrativas e controle de terminal em ambientes Windows.

Versão 1.0.0 Privacidade 100% Offline Requer Elevação Admin

01 Visão Geral da Ferramenta

O Cromak SysLock é uma suíte desenvolvida para administradores de sistemas, técnicos de suporte e usuários avançados que necessitam isolar, blindar e proteger estações Windows contra manipulações indevidas por usuários locais ou convidados.

02 Diretivas & Travas Disponíveis

O SysLock gerencia restrições em nível de máquina (HKLM) e usuário (HKCU):

Recurso Ação de Bloqueio Impacto Operacional
Gerenciador de Tarefas Desativa o Taskmgr.exe Impede finalização forçada de processos e acesso via Ctrl+Alt+Del.
Editor de Registro Trava o Regedit.exe Impede leitura ou escrita direta nas chaves do Windows.
Prompt de Comando Desativa cmd.exe e scripts .bat Proíbe abertura do terminal de comandos e execução em lote.
Janela Executar Oculta atalho Win+R Impede invocação direta de executáveis e utilitários.
Windows Installer Bloqueia motor .msi Proíbe instalação não autorizada de novos softwares na estação.
Unidade de Sistema (C:) Oculta e restringe acesso Bloqueia a navegação pelo diretório raiz do sistema operacional.

03 Gestão de Políticas de Grupo (GPO)

O Botão "Acesso às Políticas"

O controle de políticas opera como ferramenta de segurança e restauração rápida:

  • Desmarcado ao Salvar: Remove o cache local de Group Policy do Windows, restaurando as diretivas da estação para o padrão original de fábrica.
  • Marcado ao Salvar: Força uma atualização imediata via gpupdate /force em todas as diretivas ativas.

04 Operação Prática

  1. Navegue pelas abas Segurança e Sistema & Painel.
  2. Marque os recursos que deseja bloquear (o status mudará para "Bloqueado").
  3. Clique em Salvar Alterações e Aplicar Bloqueios.
  4. O Windows Explorer reiniciará rapidamente para consolidar as novas regras em tempo real.

05 Tratamento de Falsos Positivos

Nota Técnica sobre Antivírus: Como o SysLock manipula diretamente o Registro do Windows para aplicar políticas de restrição de software (o mesmo mecanismo que malwares utilizam para se ocultar), alguns antivírus heurísticos podem sinalizar o binário como falso positivo.

Para utilizar em seu ambiente corporativo ou doméstico, basta adicionar a pasta de execução à lista de exclusões do Windows Defender ou antivírus corporativo.
